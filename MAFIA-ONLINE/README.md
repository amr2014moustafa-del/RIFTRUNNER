# مافيا أونلاين

لعبة مافيا عربية متعددة اللاعبين باستخدام Node.js وSocket.IO وWebRTC.

## التشغيل
- تحتاج Node.js 18 أو أحدث.
- من داخل مجلد `MAFIA-ONLINE` نفّذ:
  `npm install`
  `npm start`
- افتح `http://localhost:3000`.

## النشر للعب مع الأصدقاء
هذا المشروع يحتاج استضافة تدعم Node.js وWebSocket (مثل Render أو Railway أو VPS)، وليس GitHub Pages وحده. فعّل HTTPS لأن المتصفح يحتاجه للسماح بالميكروفون. مكالمات WebRTC قد تحتاج TURN server حتى تعمل بثبات عبر كل أنواع الشبكات.

## قواعد النسخة الأولية
- غرف بكود خاص، 4–15 لاعباً.
- أدوار المافيا والدكتور والمحقق والمواطن.
- نهار للتحدث والتصويت، وليل للصمت واختيار المهام.
- اللاعب الخارج لا يستطيع تشغيل الميكروفون، لكنه يبقى مستقبلاً للصوت.
- زر خروج من الغرفة.

## الحالة
نسخة أولية تحتاج اختباراً عملياً متعدد الأجهزة قبل اعتبارها جاهزة للإطلاق. لا توجد خدمة استضافة أو TURN مضمنة في المستودع.
