# ASHEN OATH — The Last Ember

An original, browser-playable 3D dark-fantasy action RPG prototype by Amr.

## Play
Open `index.html` in a modern browser with an internet connection. Three.js is loaded from jsDelivr, so the first launch needs internet access.

## Controls
- **W / A / S / D** — Move
- **Mouse** — Look around (click the game once to capture the mouse)
- **Left click** — Sword attack
- **Space** — Dodge
- **E** — Rest at the glowing Ember Shrine near the start

## Goal
Defeat the four road guardians to awaken the Ashen Warden, then defeat the Warden to finish the journey.

This is an original stylized prototype. It uses simple 3D geometry and non-graphic fantasy combat.
