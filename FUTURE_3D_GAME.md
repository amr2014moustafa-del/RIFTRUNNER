# RIFTRUNNER — Future 3D Game Project

This is a separate future game, not a mode inside the current RIFTRUNNER 2D demo. Keep the current project focused on the polished 2D game until the 3D project is explicitly started.

## Intended direction
- A fully 3D action-adventure game with a professional presentation and its own identity.
- Ahmed is the main playable character.
- Third-person or otherwise clearly readable 3D exploration, with a visible sun and strong environmental lighting.
- Enemies visibly present in the world; the player can approach, fight, and explore around them.
- Distinct regions with atmosphere, environmental storytelling, and music that changes by area.
- Combat, enemy behaviors, exploration, and world progression should be designed specifically for 3D rather than mechanically copied from the 2D game.

## Important scope and quality note
- Do not build this into the current 2D game as a playable mode.
- When a future preview exists, label it clearly as **Under Development** and warn that bugs, unfinished systems, and placeholder content may appear.
- Build it as a separate game/project with its own menu, assets, controls, and release plan.
- Do not promise a professional finished result until it has been implemented and tested.
